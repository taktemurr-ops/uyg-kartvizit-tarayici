# Kartvizit Tarayıcı · Business Card Scanner

Kartı oku, alanları düzelt, vCard paylaş. · Read a card, fix the fields, share a vCard.

Verimlilik ailesinin uygulaması. Çevrimdışı çalışır; telefon, tablet ve web
(cihazda olmayan özellik için "bu cihazda yok" der).
Gerçek uygulama ortak motordadır: [verimlilik-motoru](https://github.com/taktemurr-ops/verimlilik-motoru); çatı ve
reklam/satın alma/gizlilik: [studio-core](https://github.com/taktemurr-ops/studio-core) (`lib/apps`).
Merkez uygulama: [merkez-verimlilik](https://github.com/taktemurr-ops/merkez-verimlilik).
